# Detrim AI

Приложение-пустышка: выбираешь модель и формат, жмёшь "Сгенерировать" —
идёт фейковая анимация загрузки, а затем проигрывается случайное готовое
видео из списка ссылок (VideoRepository.kt). Никакой реальной генерации нет.

## Логика

- Модели: **Detrim 1.0 Fast** (5 квот), **Detrim 2.0** (10 квот).
- Форматы: 9:16 и 16:9 (контейнер плеера меняет пропорции).
- Квоты: всего 65, тратятся по стоимости модели, обнуляются в 00:00
  (по календарной дате устройства) — см. QuotaManager.kt.
- Видео берутся из открытого набора тестовых mp4 (Google's sample bucket),
  просто как заглушка "результата генерации" — замени ссылки в
  VideoRepository.kt на свои.

## Как собрать APK

### Вариант А: без Android Studio, через GitHub Actions

1. Создай бесплатный аккаунт на github.com (если ещё нет).
2. Создай новый пустой репозиторий (New repository).
3. Загрузи туда содержимое этой папки целиком (кнопка "Add file →
   Upload files" в интерфейсе GitHub, можно перетащить всю папку/архив,
   либо через `git push`, если умеешь).
4. Убедись, что ветка называется `main` (или поправь в
   `.github/workflows/build-apk.yml` под свою ветку).
5. Открой вкладку **Actions** в репозитории — сборка запустится сама
   после загрузки файлов (или нажми "Run workflow" вручную).
6. Дождись зелёной галочки (обычно 3-5 минут).
7. Зайди в завершённый workflow-run → внизу раздел **Artifacts** →
   скачай `detrim-ai-debug-apk.zip` — внутри готовый `app-debug.apk`.
8. Перекинь apk на телефон и установи (разреши установку из
   неизвестных источников).

### Вариант Б: через Android Studio

1. Установи Android Studio (последняя стабильная версия).
2. File → Open → выбери папку DetrimAI.
3. Дай Gradle синхронизироваться (нужен интернет — подтянет зависимости).
4. Build → Build Bundle(s) / APK(s) → Build APK(s).
5. Готовый файл будет в `app/build/outputs/apk/debug/app-debug.apk`.

Для подписанного релизного APK: Build → Generate Signed Bundle / APK →
APK → создай/укажи keystore → release.

## Что можно доработать

- Свои иконки/сплэш (сейчас используется системная тема без иконки).
- Список вертикальных (9:16) видео отдельно от горизонтальных.
- История сгенерированных "видео" (сейчас показывается только последнее).
